# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately. Do not open a public issue.

Email: security@hiitl.com.

Include the version, the component (SDK, gateway, hosted service), steps to reproduce, and the impact as you understand it.

## What to expect

- Acknowledgement within two working days.
- An assessment of the report within ten working days: confirmed, not reproducible, or out of scope, with the reasoning.
- A fix and an advisory published together. We do not publish a report before a fix is available unless the reporter's own disclosure timeline requires it, in which case we say so in the advisory.
- Credit to the reporter in the advisory, unless they prefer otherwise.

## Scope

In scope: the SDKs, the evaluator, the MCP gateway, the policy and route formats, the hosted service, and the documentation where it misstates a security property.

Out of scope: a customer's own deployment configuration, policies, routes or infrastructure; social engineering; denial of service against a customer's own instance.

## Supported versions

The current minor version and the one before it receive security fixes. The changelog names each release.
